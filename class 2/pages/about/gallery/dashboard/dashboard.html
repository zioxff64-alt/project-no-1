Disadvantages of java script and python

    • 1.Slower Execution Speed: Both languages are interpreted rather than compiled directly to machine code. This overhead makes them significantly slower than languages like C++ or Rust for CPU-heavy tasks.
    • 2.Runtime Type Errors: Because they use dynamic typing, data types are checked at runtime. A typo or a mismatched data type won't break the code until that specific line runs, making large codebases harder to debug.High Memory Consumption: Both languages prioritize developer convenience and automatic memory management (garbage collection), which results in high RAM usage compared to lower-level languages.
